# Media assets

Videos and posters come from **Pexels** (free to use under the [Pexels license](https://www.pexels.com/license/);
attribution is not required but is listed here). They were trimmed, colour-graded slightly darker and desaturated
for consistency, and encoded with `npm run media -- <folder-of-raw-clips>` (`scripts/encode-media.mjs`, uses the
bundled `ffmpeg-static`). The two live-project images are screenshots of the client sites
(`node scripts/capture-work.mjs`).

Rules for all video: muted (no audio track), **< 6 s** loops (the showreel is 10 s because it plays in a modal),
**< 3 MB each**, H.264 `.mp4` (`+faststart`) **and** VP9 `.webm`. Posters are JPG. `next/image` converts them
to AVIF/WebP, resizes them and makes blur placeholders.

## Replacing footage

1. Put raw clips in a folder, named after the slot: `hero.mp4`, `showreel.mp4`, `solutions.mp4`, `process.mp4`,
   `case-1.mp4` … `case-4.mp4` (any subset).
2. Adjust start/duration/width in `SLOTS` at the top of `scripts/encode-media.mjs` if needed.
3. `npm run media -- path/to/folder`. It writes the webm, mp4 and poster for each slot (plus the portrait
   `hero-mobile.*`), then prints sizes. Keep each file under 3 MB (raise that slot's extra-CRF value if not).
4. Update the matching `alt` text in `data/cases.json`.

To refresh the live-project screenshots after a client site changes: `node scripts/capture-work.mjs`.
To go back to procedural placeholders: `npm run media:placeholders` (this overwrites the Pexels media).
